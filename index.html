What you can do

Stage a scene

Primitives, set pieces, a W/E/R gizmo, and a plan view for character paths.

Edit like Unity

Right-drag flies, WASD walks, Alt-drag orbits, F frames. Muscle memory carries over.

Author the camera

Lens, dolly, crane, cuts on a timeline. Export the move, not a prompt.

Generate motion

Pose characters, sequence Prompt Blocks, play generated motion back with IK fixes.

Quick start

Node.js 22.13+ and a Chromium browser.

npx cozyclay

Or from source:

git clone https://github.com/NomaDamas/CozyClay.git
cd CozyClay
npm install
npm run dev

FAQ

What is CozyClay?

Open source previs software in a browser: block a scene, pose characters, author camera moves and cuts, preview motion.

Previs or previz?

Same thing. Previsualization: the rough 3D pass where a shot gets blocked before anyone pays for final assets or renders.

Can I use it for camera control in AI video?

That is why it exists. Block the shot in 3D, then hand the camera move to the video model instead of describing it in a prompt. See camera control for AI video.

Do I need Blender or Unity?

No. It runs in a Chromium browser. Controls follow Unity conventions, nothing to install.

Is it free? Does it phone home?

Free, AGPL-3.0, runs on your machine and works offline. Project content is never uploaded. The npm package sends anonymous usage metrics; cclay telemetry off disables them.
