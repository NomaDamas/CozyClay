# 낙하 모캡 대안 요약

물리 기반 영상 모캡 연구는 존재하지만, 기존 나무 추락 영상을 그대로 넣으면 정확히 해결되는 제품을 확인한 것은 아니다. [src_001][src_003]
PhysHMR은 GVHMR 영상 특징과 물리 제어를 연결한다. Physical Motion Restoration은 영상 마스크 기반 수정과 물리 모방을 결합한다. [src_001][src_002][src_003][src_004]
여러 카메라를 보정해 사용하는 광학 모캡은 여러 시점으로 위치를 복원한다. 기존 단일 영상과 입력 조건이 다르다. [src_006][src_007]
비유하면 영상으로 공의 궤적을 짐작하는 것, 중력 법칙과 함께 추정하는 것, 여러 카메라로 위치를 측정하는 것의 차이다.

## 확인 필요

현재 나무 추락 영상에서 대체 모델의 낙하·착지 정확도, 속도, GPU 적합성은 미측정이다.
권고는 교체가 아니라 동일 영상의 별도 A/B 시험이다. PhysHMR은 사람과 장면의 상호작용을 명시적으로 지원하지 않아 나무의 지지를 포함하는 장면은 특히 검증해야 한다. [src_001]
