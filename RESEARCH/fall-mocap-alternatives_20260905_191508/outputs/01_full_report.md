# GVHMR 낙하 문제를 다루는 모캡 기술
기준: 2026-09-05. 공개 논문·공식 구현을 확인했으며, 앱 코드 변경이나 모델 실행은 하지 않았다.

## 확인된 기술

| 기술 | 확인한 구조 | 적용 판단 |
|---|---|---|
| PhysHMR | GVHMR 영상 특징을 물리 시뮬레이터의 제어 정책에 입력. 2D 영상 관측으로 전신 위치를 유도한다. [src_001][src_002] | 기존 모델과 연관된 시험 후보. 공식 저장소는 준비된 평가 데이터의 실행 예제를 제공한다. |
| Physical Motion Restoration | 영상 마스크·문맥으로 추정 동작을 수정한 뒤 물리 기반 동작 전이를 수행한다. [src_003][src_004] | 고난도 동작 복원 설계 참고. 공식 고난도 동작 데모가 있으나 여기서는 영상을 재생하거나 모델을 실행하지 않았다. [src_005] |
| Vicon / OptiTrack 광학 모캡 | 보정된 여러 카메라의 겹치는 관측으로 3D 마커 위치를 복원한다. [src_006][src_007] | 촬영부터 여러 시점이 필요하며 가림과 보정 문제는 남는다. |

단일 영상 추론에 물리 모델을 결합하는 연구 방향은 실제 존재한다. [src_001][src_003]
비유하면 공이 떨어지는 영상을 눈으로 추측하는 것과 중력 법칙을 함께 이용하는 것, 여러 카메라로 공의 위치를 측정하는 것의 차이다.
서로 다른 도메인의 논문·공식 코드 확인은 구조 확인일 뿐, 같은 저자 연구의 독립 성능 재현을 뜻하지 않는다.

## 확인 필요 / 한계

PhysHMR 논문은 사람–장면 상호작용을 명시적으로 지원하지 않는다고 밝힌다. 나무에 지탱되다가 떨어지는 장면 전체를 해결했다는 근거가 아니다. [src_001]
논문의 물리 기반 평가에는 실패 클립 제외가 포함되므로 평균 수치를 무조건적인 동작 성공으로 해석할 수 없다. [src_001]
현재 나무 추락 영상에서 낙하 시작·착지 시점, 전신 높이 궤적, 관절 자세, 처리 시간, GPU 메모리는 대체 모델로 측정하지 않았다.
Physical Motion Restoration의 바로 실행 가능한 공개 코드·가중치 확보 여부는 이번 확인 범위에서 확정하지 않았다.
각 모델의 상용 이용 조건도 별도 검토 대상이며, 공개 저장소 존재가 상용 허가를 의미하지 않는다.

## 제안: 교체 전 동일 영상 A/B

CozyClay에서는 기존 추출을 유지하고 PhysHMR 같은 후보를 별도로 평가하는 것이 적절하다는 판단이다. 즉시 교체 권고는 아니다.
판정 조건은 나무의 지지 → 지지 해제 → 공중 이동 → 착지까지 원본과 맞는지다. 물리적으로 자연스러워도 원본 자세를 바꾸면 실패다.
지표는 착지 시점 오차, 원본 영상으로 재투영한 위치·자세 오차, 바닥 침투와 접촉 미끄러짐, 연산 시간이다. 절대 3D 높이 정확도에는 별도 실제 치수나 다중 시점 기준이 필요하다.
리서치 검증 절차 때문에 대체 후보를 발견했다는 사실과 정확한 영상에서 해결이 입증됐다는 주장을 분리했다.
